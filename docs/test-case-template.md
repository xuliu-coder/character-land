# 测试用例模板

每个功能任务完成后，按此模板进行功能验证。

---

## 用例模板

| 字段 | 说明 |
|------|------|
| **用例编号** | TC-{Phase}-{序号}，如 TC-01-01 |
| **关联任务** | 对应 dev-log 中的任务编号，如 1.1 |
| **测试标题** | 简短描述测试目标 |
| **前置条件** | 测试前需要满足的状态 |
| **测试步骤** | 操作的详细步骤 |
| **预期结果** | 期望看到的结果 |
| **实际结果** | ✅ 通过 / ❌ 失败 |
| **备注** | 失败时记录具体现象 |

---

## 各Phase核心验证点

### Phase 1: 基础框架
- [ ] 三个Tab按钮可见且可点击
- [ ] Tab切换时内容区正确显示/隐藏
- [ ] 导航栏激活态样式正确
- [ ] 页面颜色与设计文档一致

### Phase 2: 角色上传
- [ ] 点击上传区域能选择文件
- [ ] 拖拽文件能识别
- [ ] JPG/PNG正常通过，其他格式被拒绝
- [ ] >5MB文件被拒绝
- [ ] 原图预览正确显示
- [ ] 名称为空时点生成有提示
- [ ] 错误弹窗可关闭

### Phase 3: 像素化算法
- [ ] 上传图片后点击生成能看到像素化效果
- [ ] 像素块大小参数调整后效果变化
- [ ] 生成时间 ≤2秒
- [ ] 重新生成能产生不同效果
- [ ] 确认保存按钮可点击

### Phase 4: 数据存储
- [ ] 保存角色后刷新页面，角色仍在
- [ ] 角色库正确展示所有已保存角色
- [ ] 编辑角色信息后正确更新
- [ ] 删除角色后从列表移除
- [ ] IndexedDB不可用时降级到LocalStorage

### Phase 5: 场景编辑器
- [ ] 三栏布局正确显示
- [ ] Canvas网格背景可见
- [ ] 角色可拖入画布
- [ ] 角色可选中和移动
- [ ] 旋转/缩放操作正确
- [ ] 属性面板数据实时同步
- [ ] 场景模板切换正常
- [ ] Ctrl+Z撤销可用

### Phase 6: 导出功能
- [ ] 导出图片包含背景+所有角色
- [ ] 角色位置/旋转/大小与画布一致
- [ ] 1x/2x分辨率选择生效
- [ ] 浏览器正确触发下载

### Phase 7: 错误处理
- [ ] 所有错误场景有中文提示
- [ ] 存储空间不足时提醒
- [ ] 浏览器不支持IndexedDB时降级

### Phase 8: 测试优化
- [ ] Chrome功能完整
- [ ] Edge功能完整
- [ ] Firefox功能完整
- [ ] 拖拽响应 <100ms
- [ ] 页面加载 <3s
